IVE — Looks Can Kill

Open index.html to explore the website. All supplied imagery and the display font are included.

The hero embeds YouTube video iBeo74ujfes, muted and looping, and has a Play/Pause background control. It keeps the original photo visible until playback starts. Selecting a numbered photo pauses the video. Reduced-motion preferences turn autoplay off.

YouTube video playback requires internet access and permission from the video's owner to embed it. YouTube can block embeds opened directly from a local file. For video playback, serve this folder from a website or local web server (for example: python -m http.server 8000, then open http://localhost:8000).

No video was downloaded or copied; the video is played using the official YouTube embedded player.
